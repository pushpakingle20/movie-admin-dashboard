# 🎬 Movie Admin Dashboard

A modern and responsive Admin Dashboard for a Movie Booking System built with React 19 and UnoCSS.

---

## 🚀 Tech Stack

- React 19 (JavaScript - JSX only)
- UnoCSS (Utility-first CSS framework)
- Lucide React (Icons)
- Recharts (Analytics Charts)
- React Big Calendar
- Moment.js
- Vite

---

## ✨ Features

- 📊 Dashboard Cards (Users, Tickets, Revenue)
- 📅 Movie Show Calendar
- 📈 Analytics Charts
- 🎥 Movies Table with Search Filter
- 🌙 Dark / Light Mode Toggle
- 📱 Fully Responsive Layout
- 📌 Sidebar Navigation with Icons
- ⚡ Smooth UI with Modern Design

## 🛠️ Installation & Setup

Follow these steps to run the project locally:

1️⃣ Clone the repository:



git clone https://github.com/pushpakingle20/movie-admin-dashboard.git


2️⃣ Navigate into the project folder:



cd movie-admin-dashboard


3️⃣ Install dependencies:



npm install


4️⃣ Start the development server:



npm run dev


The app will run at:



http://localhost:5173

⚠️ Replace your-username with your actual GitHub username.
